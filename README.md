# Simple Web Calculator

A sleek, responsive, and lightweight calculator built with pure HTML, CSS, and Vanilla JavaScript.

## Features
- **Modern UI:** Clean dark-mode interface with smooth button press animations.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop screens.
- **Arithmetic Operations:** Addition (`+`), subtraction (`-`), multiplication (`×`), division (`÷`), and percentage (`%`).
- **Input Controls:** All Clear (`AC`), Delete (`DEL`), and Equals (`=`).
- **Keyboard Navigation:** Full support for standard numpad and keyboard shortcuts (Numbers, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`).
- **Zero Dependencies:** Pure HTML5, CSS3, and JavaScript.

## Project Structure
```text
calculator/
├── index.html     # HTML structure
├── style.css      # Dark theme styling and layout
├── script.js      # Calculator arithmetic and interaction logic
└── README.md      # Documentation
```

## Running Locally
Simply open `index.html` in any modern web browser or serve it locally using Python:

```bash
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080`.
